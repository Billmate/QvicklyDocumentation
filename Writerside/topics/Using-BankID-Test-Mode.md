# Using BankID Test Mode


To test flows or products requiring BankID identification, you must use a test BankID account and configure your client for test mode.

For step-by-step instructions on downloading the app, configuring for test, issuing a test BankID, and troubleshooting,  see [here](https://developers.bankid.com/test-portal/bankid-for-test).


**Note**: Test BankID accounts are only for test mode and cannot be used in production.
